# No reply/thread model for comments

Redline is a solo-review tool — the reviewer is the only author of their comments, not one participant in a multi-person discussion — so a [[Comment]] anchored to a diff range has no reply chain, and revising one means editing it in place rather than adding a reply underneath. This is why `CommentThread.svelte` only ever renders a single comment (`comments.slice(0, 1)`) and shows no input once a comment exists: that is the intended v1 shape, not an unfinished reply feature. Multi-party review — syncing GitHub PR review threads, say — would need this revisited.
